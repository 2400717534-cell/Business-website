# Wisdom Cloud Media

Lightweight PHP 8.2 site for XAMPP. Homepage uses PHP, HTML, Bootstrap 5 via CDN, custom CSS and vanilla JavaScript. No Composer, Node, Docker or framework required. The admin and MySQL workflows are the next implementation stage.

## Run
Place this folder in `C:\xampp\htdocs` (or point an Apache virtual host at it), start Apache in XAMPP, then visit `http://localhost/<folder-name>/`.

Bootstrap assets load from jsDelivr, so a browser internet connection is needed. The homepage is static for now; no database is created or connected in this stage.
